# AI Chat & Video для iPhone

Тестовое задание: AI-чат (Dola API) и генератор видео по шаблонам
(PixVerse API), онбординг, пейвол на Apphud, история чатов и видео,
настройки. UI — по макету Figma.

## Запуск

Двойной клик по `Build.command` в Finder. Скрипт сам поставит XcodeGen
(если его нет), сгенерирует проект, соберёт и запустит приложение в
симуляторе. Если macOS не даёт открыть файл — правый клик → «Открыть».

- Нужен Xcode 26. Минимальная iOS — **16.0**; рантайм iOS 16 для симулятора
  ставится отдельно (Xcode → Settings → Components).
- Токен API и ключ Apphud уже лежат в проекте в обфусцированном виде
  (`AIChat/Data/Secrets/Secrets.generated.swift`, XOR с солью). Поменять:
  `NEBULA_API_TOKEN=… APPHUD_API_KEY=… python3 scripts/gen_secrets.py`.
  Это защита от сканеров секретов, не от реверса — настоящая требует своего
  прокси-сервера.
- **Если на Mac включён VPN**, симулятор может не резолвить DNS
  (`nebulaapps.site`) — приложение покажет «No internet connection». Без VPN
  или на устройстве запросы идут.

## Архитектура

MVVM + offline-first. База GRDB — единственный источник правды для чатов и
видео: экраны читают её через `ValueObservation`, сеть только пишет в базу
через сервисы. `ChatService` и `VideoGenerationService` живут в
`AppContainer` и владеют сетевыми задачами, поэтому уход с экрана не
отменяет ни ответ, ни генерацию видео.

- `App/` — композиция (`AppContainer`, роутер, DEBUG launch-аргументы);
- `Features/` — экраны: View + ViewModel (`ObservableObject`, `@MainActor`);
  `Features/Shared/` — тема (токены Figma, шрифт Inter) и общие компоненты;
- `Domain/` — модели, протоколы, сервисы (без UIKit, GRDB, Apphud);
- `Data/` — GRDB, HTTP-клиент, Dola, PixVerse, Apphud, файлы, секреты;
- `Mocks/` — фейки только под `#if DEBUG`.

Зависимости (SPM, `exactVersion`): GRDB и ApphudSDK. Свой сетевой слой на
`URLSession` + `async/await`. Шрифт Inter (OFL) — 4 начертания в бандле.

## Что сделано

- **Онбординг**: сплэш с прогрессом → 2 экрана (свайп или Continue) →
  пейвол → главный; показывается один раз.
- **Пейвол (Apphud, paywall `main`)**: планы и цены из продуктов пейвола,
  экономия в процентах, крестик через 2 с, Restore, Terms of Use. Показ —
  после онбординга, по PRO, из настроек и при попытке премиум-действия.
  Статус подписки обновляется сразу после покупки, без перезапуска.
- **Премиум-доступ**: без подписки отправка в чате, Regenerate/Retry и
  Create видео открывают пейвол; введённый текст и выбранное фото не
  теряются.
- **AI-чат (Dola)**: ответ приходит целиком — пока ждём, анимация «печатает»,
  Send неактивна; ответ появляется плавно. Markdown (заголовки, списки,
  код с Copy), Copy и Regenerate, меню чата Share / Pin / Delete,
  подсказки на пустом экране. Контекст хранит сервер по `chat_id`.
- **Offline-first**: без сети сообщение сохраняется как `pending` и уходит
  само при появлении сети, запуске и возврате в foreground — ровно один раз.
  Ответ, прерванный закрытием приложения, помечается и получает Try again.
- **Генератор видео (PixVerse)**: шаблоны по категориям (первый кадр превью
  с кэшем), карусель шаблонов с проигрыванием превью, выбор фото, формат и
  качество; генерация с опросом статуса продолжается вне экрана и после
  перезапуска; результат — проигрывание, Download в Фото, Share, Replace.
- **История**: чаты (закреплённые, папки, группы по датам, свайп Rename /
  Move / Delete) и видео (masonry-сетка, In progress / New / Error +
  Try again).
- **Настройки**: Rate, Share, Upgrade plan, уведомления, Clear cache с
  размером, Restore purchases, ссылки, версия приложения.
- **Ошибки** различаются: нет сети / 401 / 402 / 403 / 429 / 5xx — у каждой
  свой текст и Try again; отмена — не ошибка.
- Haptics, тёмная тема, Dynamic Type, английский интерфейс + русский перевод.

## Не сделано и известные ограничения

- **Живой API из приложения в симуляторе не проверен.** На машине разработки
  включён VPN, и DNS в симулятор не проходит. Контракты Dola и PixVerse
  проверены реальными запросами с Mac (консольная проба и
  `LiveAPIProbeTests` с `LIVE_API=1`); сетевой слой, маппинг ошибок и
  декодирование покрыты юнит-тестами на фикстурах реальных ответов.
- **Покупки и restore в Apphud не проверены** (нужны sandbox-аккаунт и сеть).
  Поток покупки проверен на фейковом сервисе подписки.
- **На устройстве не запускалось** — только симуляторы.
- Генерация видео через настоящий PixVerse в приложении не проверена (сеть,
  см. выше). Весь путь Create → генерация → результат → Download / Share →
  история проверен вручную на iOS 16 и 26 в `-mockData`: там «генерация» — пара
  статусов `generating`, затем локальный mp4, отрендеренный из выбранного фото.
- UI-тесты не запускаются на симуляторе iOS 16.4: раннер XCTest из Xcode 26
  не подключается («hung before establishing connection»). На iOS 26 они
  проходят; на iOS 16.4 проходят юнит-тесты, экраны проверены вручную.
- 4K в UI отправляется в API как 1080p (API выше не умеет). Формат 16:9 /
  9:16 / 1:1 — центр-кроп фото перед отправкой: параметра пропорций в API нет.
- Нет ссылок на Privacy Policy, Usage Policy, Contact us и App Store (Rate,
  Share): кнопки есть, но ничего не открывают. Terms of Use — стандартный
  EULA Apple.
- История чатов локальная, с сервером не синхронизируется.
- В iOS 16–18 свайп-действия в истории прямоугольные (системные), в iOS 26 —
  круглые, как в макете.
- Утечки проверены `leaks` (0 после исправления); профилирование
  Allocations в Instruments не делалось.

## Как проверяли

- Симуляторы: iOS 26.5 (iPhone 17) и iOS 16.4 (iPhone 14).
- Unit-тесты (Swift Testing, 237): сетевой слой и маппинг ошибок, Dola и
  PixVerse на фикстурах, `ChatService` (outbox ровно один раз, retry,
  прерванные ответы), `VideoGenerationService` (опрос, возобновление,
  ошибки), контрактные тесты репозиториев (in-memory и GRDB), миграции,
  Markdown, ViewModel, пейвол, форма ключей (без значений), полнота
  русского перевода.
- UI-тесты (XCUITest, 10): первый запуск, ответ чата и Copy, пейвол без
  подписки с сохранением текста, 429, офлайн, PRO у бесплатного, шаблоны,
  превью и выбор формата, переименование в истории, Upgrade plan в настройках.
- Вручную на iOS 16.4 и 26.5: онбординг, пейвол и покупка на фейке, чат,
  ошибки, шаблоны, выбор фото (системный запрос доступа), формат 16:9 и 9:16,
  генерация, результат, Download в «Фото», Share, история видео.
- Ошибки — DEBUG launch-аргументами, без правки кода:
  - `-mockOffline` — сообщение получает «Will send when online»;
  - `-mockError 401|402|403|429|500` — свой текст ошибки и Try again;
  - `-mockFree` / `-mockPremium` — подписка; `-mockSlowReply` — долгий ответ
    чата;
  - `-mockData` — демо-чаты и папки, фейковый каталог шаблонов и «генерация»
    видео без сети (результат — mp4 из выбранного фото); всё в памяти,
    настоящая история не затрагивается;
  - `-resetOnboarding`, `-skipOnboarding`.
