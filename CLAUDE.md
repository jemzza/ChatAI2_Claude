# CLAUDE.md — правила для агента

Ты работаешь над тестовым заданием: iOS-приложение с AI-чатом (Dola API) и
генератором видео по шаблонам (PixVerse API), онбордингом, пейволом (Apphud),
историей и настройками — по макету Figma. Перед работой прочитай
`docs/task.md` (что и зачем) и `docs/plan.md` (по каким шагам идём).

## Порядок работы

1. Бери **один** следующий невыполненный шаг из `docs/plan.md`. Не забегай вперёд.
2. Перед кодом коротко опиши, что собираешься сделать, и какие файлы затронешь.
3. После изменений **обязательно собери проект** (команда ниже). Шаг не готов,
   пока сборка не зелёная. Если есть тесты по шагу — прогони их.
4. Отметь шаг в `docs/plan.md` как `[x]` и сделай коммит.
5. Если решение отличается от плана — сначала обнови план/`docs/task.md`
   (раздел «Решения»), потом код.
6. Шаг с пометкой 👤 в плане — остановись и попроси пользователя сделать
   свою часть; не пытайся обойти.

## Figma

- Макет — источник правды для UI: fileKey `7X0uQl95zcP3KPMmB1G8ix`, id секций —
  в `docs/task.md`. Читай через Figma MCP: `get_metadata` (структура),

- Заметки под экранами (жёлтые/розовые карточки) — часть ТЗ: поведение,

- Картинки-плейсхолдеры из макета (фото людей, шаблоны) в репозиторий не
  кладём; в UI — данные из API. Иконки — SF Symbols, если в макете
  стандартная иконка; кастомные — экспорт из Figma в `Assets.xcassets` (PDF/SVG).

## Коммиты

- Маленькие, по одному логическому изменению, сообщения на английском в

## Архитектура (не отступать без обновления docs/task.md)

- **MVVM.** View — только разметка и биндинги. Логика — во ViewModel
  (`ObservableObject` + `@Published`, `@MainActor`). ViewModel не импортирует
  GRDB и ApphudSDK.
- **Offline-first.** База (GRDB) — единственный источник правды для чатов и
  видео. UI читает только из базы через `ValueObservation` → `AsyncSequence`.
  Сеть только пишет в базу через сервисы (`ChatService`,
  `VideoGenerationService`), которые живут в `AppContainer` и владеют
  сетевыми задачами — уход с экрана их не отменяет.
- **Слои:** `App/` (композиция, `AppContainer`, роутинг), `Features/<Name>/`
  (View + ViewModel), `Domain/` (модели, протоколы, сервисы — без зависимостей
  от UIKit/GRDB/Apphud), `Data/` (GRDB, HTTP-клиент, Dola, PixVerse, Apphud,
  Keychain, секреты), `Features/Shared/` — переиспользуемые компоненты.
- Зависимости передаются через инициализаторы и протоколы. Никаких синглтонов,
  кроме `AppContainer` в точке входа (и вызова `Apphud.start` внутри
  `ApphudSubscriptionService`). DI-фреймворки не использовать.
- Модели домена — `struct`/`enum`, `Sendable`, `Hashable` (`Domain/Models/`),
  протоколы — `Domain/Protocols/`.
- Фейки — только в `AIChat/Mocks/` под `#if DEBUG`. `AppContainer` по умолчанию
  собирает реальные реализации; фейк подключается только своим
  launch-аргументом (`LaunchOptions`).
- Зависимости: GRDB и ApphudSDK. Новые SPM-зависимости — только с
  обоснованием в `docs/task.md`. CocoaPods запрещён.

## Swift и платформа

- Минимум **iOS 16**. Всё, что новее (`@Observable`, `onChange` с двумя
  параметрами, `.sensoryFeedback`, `ContentUnavailableView`, `.scrollPosition`,
  Liquid Glass и др.), — только за `if #available(...)`. Проект обязан
  собираться и работать на iOS 16.
- Swift 6, строгая конкурентность. Не глуши предупреждения через
  `@unchecked Sendable` / `nonisolated(unsafe)` без комментария «почему».
- Без force unwrap (`!`) и `try!` в продакшен-коде (в тестах можно).
- Язык интерфейса — **английский**. Каждая строка, которую видит
  пользователь, идёт через String Catalog (`Localizable.xcstrings`):
  `LocalizedStringKey` (литерал в `Text`/`Button`), `String(localized:)` или
  `LocalizedStringResource`; ключ — английская фраза. Без хардкода:
  никаких `Text(verbatim:)` и обычных `String` из кода в UI (кроме данных:
  текст сообщений, названия шаблонов из API, цены из StoreKit). Русский
  перевод (`ru`) есть: каждую новую строку добавляй в каталог сразу с
  переводом (пропуск ловит `LocalizationTests`). Документация (`docs/`,
  `CLAUDE.md`, README), комментарии — на русском, коммиты — на английском.
- Тема только тёмная (как в макете). Цвета — из `Assets.xcassets` / `Theme`
  (токены из Figma) или системные; захардкоженные RGB во View запрещены.
  Шрифт — системный SF Pro, размеры через Dynamic Type-стили из `Theme`.
- Только iPhone, портрет.

## Секреты — строго

- **Никогда** не печатай, не логируй и не проси токены/ключи. Не читай файлы,
  где они могут быть открытым текстом (`.env`).
- Bearer-токен Nebula API и ключ Apphud попадают в проект только через
  `scripts/gen_secrets.py` из переменных окружения (`NEBULA_API_TOKEN`,
  `APPHUD_API_KEY`). `Secrets.generated.swift` содержит только
  обфусцированные байты; не открывать. `gen_secrets.py` запускает только
  пользователь.
- Не добавляй токены в URL, `print`, тексты ошибок, тесты, коммиты, доки.
  Тест ключей проверяет только форму (префиксы `eyJ` / `app_`, длина),
  значения сводятся к `Bool` до `#expect`.
- Access/refresh-токены клиентской сессии — только в Keychain.
- Перед коммитом `git grep -lE "eyJ[A-Za-z0-9_-]{20,}|app_[A-Za-z0-9]{20,}"`
  должен быть пуст (только `-l`, чтобы не печатать найденное).

## Поведение, которое нельзя сломать

- Ответ чата приходит целиком; пока ждём — анимация генерации, Send неактивна.
  Готовый ответ появляется плавно, без скачка ленты.
- Сообщение без сети сохраняется как `pending` и уходит само, когда сеть
  появилась (а также при запуске и возврате в foreground) — ровно один раз.
- При запуске ответы в статусе `generating` → `interrupted`; опрос
  генерирующихся видео возобновляется.
- Генерация видео продолжается при уходе с экрана и видна в History
  (In progress → New / Error + Try again).
- Без активной подписки премиум-действия (отправка в чате, Create видео)
  открывают пейвол; введённое пользователем не теряется. После покупки доступ
  открывается сразу, без перезапуска.
- Ошибки различаются по таблице в `docs/task.md` (нет сети / 401 / 402 / 403 /
  429 / прочее) — у каждой понятный текст и «Try again». Отмена — не ошибка.
- Сценарии ошибок проверяем DEBUG launch-аргументами (`-mockOffline`,
  `-mockError <code>`, `-mockFree`/`-mockPremium`), а не временной правкой кода.

## Когда остановиться и спросить

- Нужно менять архитектуру или добавлять зависимость.
- Требование из `docs/task.md` или заметка в Figma противоречат друг другу.
- Макет неоднозначен (нет состояния, непонятное поведение).
- Сборка не чинится за 2–3 попытки — опиши, что пробовал.
