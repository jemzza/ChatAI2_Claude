# План

Агент идёт по шагам **сам, подряд**: после каждого — сборка, тесты, отметка `[x]`,
коммит, отчёт. Останавливается только на шагах **👤**, на решениях про
архитектуру/продукт/безопасность/платный функционал и на ошибках, которые не
чинятся за 2–3 попытки.
Каждый UI-шаг: перед кодом — `get_design_context` / `get_screenshot` нужных
узлов Figma и заметок под ними; после — скриншот из симулятора рядом с макетом.

У каждого шага: **Готово, когда** — критерии приёмки; `коммит` — сообщение
(Conventional Commits). Сборка и тесты зелёные — неявный критерий всех шагов.

> План предыдущего проекта (стартовый AI-чат на Groq) — в истории git.

- 0.2: `deploymentTarget` остался 18.0 — стартовый код использует `Mutex`,
  `@Observable` и другие API iOS 17–18, сборка под 16 падает. Переключение на
  16.0 перенесено в 0.4, вместе с переводом кода. Строки микрофона и
  распознавания речи в Info.plist удалим в 0.3 вместе с голосом.
- 0.3: удалены и экраны чата/списка (`ChatView`, `ChatViewModel`,
  `ChatListViewModel` и их тесты), а не только сайдбар — по макету они
  устроены иначе и будут написаны заново в 6.4/6.9 (старый код — в истории
  git). Оставлены база (`ChatRepository`, папки, вложения), `ChatService`
  без «Answer offline», `NotificationService`, Markdown-парсер. Убраны
  перетаскивание чатов (свой `UTType`) и строки микрофона/распознавания.
  `DependencyPlan.Model.groq` → `.live`; реальный провайдер — в 3.2.
- 0.4: `Mutex` заменён своим `Locked` (`Domain/Support`, `NSLock`, тот же API).
  `@Observable` был только у хранилища настроек — оно стало `ObservableObject`;
  тема (`appearance`, `AppearancePreference`) убрана — приложение только тёмное.
  `Theme` временно упрощён (без serif и цветов через `ColorResource`, который
  есть только с iOS 17) до шага 5.1. Рантайма iOS 16 на машине нет — сборка
  проверена с целью 16.0, тесты — на iOS 26; прогон на iOS 16 — в 7.3.
- После 0.5 (решение заказчика): коммиты — Conventional Commits; агент идёт
  по шагам без подтверждения каждого; у шагов — критерии приёмки; после шага —
  отчёт (файлы, сборка/тесты, статусы проверки, ограничения, коммит).
- 1.1: `ErrorKind` расширен (`paymentRequired`, `notFound`, `validation`,
  `decoding`), `unsupportedLanguage` убран. Новая `APIError` пока живёт рядом
  с `LLMError` — `LLMError` уйдёт вместе с `LLMProvider` в 3.2.
- 1.3: реальные запросы показали, что у Dola v3 (клиентские сессии) не
  развёрнут — 404; v1 с Bearer владельца и `user_id`/`app_id` в query работает
  у обоих сервисов и совпадает с данными ТЗ. Код 1.2 (сессии, Keychain)
  удаляем отдельным шагом 1.4. Симулятор здесь не резолвит DNS — пробы
  выполнены консольной программой на Mac (`LiveAPIProbeTests` — тот же код).
- 2.1: статус подписки — `Apphud.hasPremiumAccess()` (подписка или покупка),
  обновление — по `Apphud.didUpdateNotification()` вместо `ApphudDelegate`
  (протокол не `Sendable`). `-mockPremium`/`-mockFree` добавлены сразу (были
  в 7.1) — нужны UI-тесту, чтобы не стартовать настоящий Apphud. Старт SDK в
  реальном запуске не проверен: симулятор здесь без DNS.
- 2.2: «SAVE N%» считаем сами — от самой дорогой в неделю цены среди тарифов
  пейвола (в макете числа условные). Тарифы — StoreKit 2 `Product` из
  `ApphudProduct.product()`. Пейвол ищем по id `main` среди пейволов
  плейсментов (и по id плейсмента — на случай другой настройки дашборда).
  Реальная загрузка продуктов, покупка и restore не проверены (нужны sandbox и
  сеть в симуляторе) — проверка в 7.3.
- 3.1: закрепление — один метод `setPinned(chatId:at:)` (`nil` — открепить).
  Статус `cancelled` оставлен: «Стоп» в макете нет, но удалять значение из
  базы ради этого незачем; типы черновика стрима уйдут в 3.2.
- 3.2: `LLMProvider`/`LLMMessage`/`LLMError` и черновик стрима удалены;
  вместо них `ChatProvider` (ответ целиком) и `APIError`. Фото к сообщениям

  `AppContainer` и запускает outbox. Реальный ответ Dola из симулятора не
  проверен (DNS), с Mac — проверен в 1.3.
- 4.1: генерация хранит имена файлов (фото, скачанное видео), а не пути —

- 4.2: последний каталог шаблонов сохраняется файлом и отдаётся без сети
